# WARPATH УСТАВ — Интерактивный двухтомный справочник

Полная журнально-книжная энциклопедия и полевой устав по **Warpath: Ace Shooter** (версия **v14.60**).  
Стек: чистый **HTML5 / CSS3 / Vanilla JS** без фреймворков, адаптивная вёрстка от `360px`, офлайн-прогресс в `localStorage`.

🌐 **Онлайн-версия (GitHub Pages):** https://228burger228.github.io/warpathGideVibe/

---

## 📚 Тома на Книжной полке

- **[index.html](index.html) — Том I: Полевой устав и полный справочник (22 главы, 48 страниц)**
  - **I–II. Старт и экономика:** разделение ресурсов (база, юниты, офицеры, оперсети), выбор лагеря, первый день, дисциплина F2P, трата золота (VIP 4/9), Чёрный рынок и Arms Race.
  - **III–IV. Армия, тактика и ТВД:** все юниты (`ТТ`, `ШХ`, `ПТ`, `ПТО`, `Арта`, `RL «Катюша»`, `VADS/Флак`), система контров (КНБ + SVG-схемы), рабочие связки офицеров `14.5–14.60`, сборка 5 слотов, оборона базы и экспедиции.
  - **V–VI. Штаб, Мета и Оперсети:** интеграция с `@shevchenko01_bot`, словарь сленга, Центр оперативной информации (120+ дн., цикл 180 дн., Разгон процессора), бункер-тесты навыков, тактика ВВС/ВМС и правила **Офицерского обмена** (`3` слота: `2` обычных + `1` эксклюзивный).
  - **VII. Полный справочник от А до Я (стр. 37–48):** боевые формулы (*Приведённая броня*, **сквозное пробитие «навылет»**, капы `80%` / `60%` / `30%`), путь `4★ → 7.2★ → Прототип → 9.2★ (XV–XVI)`, ограничения лиг (Серебро / Золото III–I / Легенд.), 4 стены базы и Зал отдыха Кэт, все рода войск (Суша / Небо / Море) и 33–36 ур. базы (Совместный тактический цех, титановый сплав и иридий), календарь событий и чеклисты роста (**Новичок → Мид → Профи**).

- **[updates.html](updates.html) — Том II: Хроника обновлений `v12.0 → v14.60` (8 глав, 18 страниц)**
  - Быстрая выжимка патчей для вернувшихся игроков: эра `9.2★`, чипов и Титанов, Центр оперативной информации, Воздушные группы и ВМС, 36-й уровень построек (`14.4`), пятёрка офицеров `14.5`, Офицерский обмен, 16 навыков Гегемона, новый Зал вербовки и Техас (`14.6`).

## 🛠 Функции интерфейса и инструменты

- **Книжная полка справа (`Полка`):** переключение между **Томом I**, **Томом II** и выпадающим выбором **Внешних справочников**:
  - **WP Commander** — актуальные калькуляторы VIP, напитков, обмена и база кодов;
  - **SpeedPath (EN)** — база на 206 скинов / 668 деталей (`I–XV`), чеклисты и минорные патч-ноты;
  - **WarpathYTwiki (архив)** — старый справочник автора (не обновляется).
- **Боковое меню «Видео» слева:** контекстные YouTube-подборки именно под текущую открытую главу от авторов сообщества (`@burgerdom6`, `@e6aka56`, `@VNwarpath1`, `@MoreScop3s`, `@Twon22`, `@ItsEhson`, `@ClanGothic`).
- **Самоулучшение гайда («Нашли ошибку?»):** кнопка на экране над книгой открывает форму тикета с привязкой к текущему тому, странице и главе — отправляется в GitHub Issues или копируется для [@shevchenko01_bot](https://t.me/shevchenko01_bot) и чата [WarpathHub](https://t.me/WarpathHub/1).
- **Модальное окно «Штаб» (`#hq-dialog`):**
  - **Тикеты и Вопросы:** формирование шаблона тикета и прямые ссылки на чат [WarpathHub](https://t.me/WarpathHub/1), GitHub Issues и бота [@shevchenko01_bot](https://t.me/shevchenko01_bot) (калькулятор обмена + команды `link` / `stats` / `c4`);
  - **Промокоды:** список из **16 кодов** (сверка с базой WP Commander и патчами `14.4–14.6`), копирование в буфер обмена в 1 клик, отметка использованных и переход на [портал Лилит](https://cdkey.lilith.com/warpath-global);
  - **Калькулятор:** экспресс-оценка мощи юнита, атаки, защиты и HP;
  - **Комьюнити:** сводный каталог всех проверенных каналов, ботов и баз.
- **Удобство чтения и игровые подсказки:** 2-страничный книжный разворот на ПК (1 страница на мобильном), встроенные всплывающие пояснения терминов прямо в тексте (как в игре), боковые стрелки, клавиатура (`←` / `→`, `/` для поиска, `Esc`), свайпы на телефоне, скраббер страниц, тёмная/светлая тема, озвучка текста (Web Speech TTS) и звук страниц.


## 🚀 Локальный запуск

Проект полностью статический и не требует сборки (`npm` / бандлеров):

```bash
git clone https://github.com/228burger228/warpathGideVibe.git
cd warpathGideVibe
python -m http.server 4173
```

После запуска откройте `http://localhost:4173/index.html`.
