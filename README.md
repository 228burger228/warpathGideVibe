# WARPATH GUIDE — Интерактивное тактическое руководство

Интерактивная книга-руководство по игре **Warpath: Ace Shooter** в эстетике `riseof.ru` на чистом **HTML5 / CSS3 / Vanilla JS**.

## Возможности
- **Формат книги-устава:** перелистывание страниц кнопками, свайпами и стрелками клавиатуры (`←` / `→`).
- **Интерактивное содержание:** быстрый переход по 12 главам (26 страниц) с трекером прогресса (`localStorage`).
- **Режим «Пропускать доп. страницы глав»:** переключение только по ключевым страницам глав.
- **Быстрый поиск (`/`):** мгновенный полнотекстовый поиск по юнитам, офицерам, ресурсам и советам.
- **Озвучка страниц (TTS):** чтение текста текущей страницы через Web Speech API (`ru-RU`).
- **Темы оформления и Fullscreen:** тёмная (по умолчанию) и светлая пергаментная тема, адаптивность от `360px`.

## Структура проекта
- `index.html` — семантический каркас книги, верхняя панель и модальные `<dialog>` (поиск, оглавление).
- `css/style.css` — дизайн-система («Бизнес-Премиум» / тактический пергамент), обрез страниц и адаптив.
- `js/book-data.js` — структурированная база знаний (данные из `WarpathYTwiki` и актуальных гайдов 2025–2026).
- `js/app.js` — движок рендера страниц, навигации, поиска, прогресса и озвучки.
